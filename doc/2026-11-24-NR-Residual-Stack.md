# NR 差分叠层

日期 2026-11-24

专业模式新增「添加性能 NR 层」，与「添加 NR 层」共用四层上限和连续编号。性能层在同一连续 NR 段中取当前输出与段入口的差分，通过 GPU 合成再次叠加，省去该层的模型推理。叠加强度、明暗、色彩和细节参数可单独调节。每层耗时在 GPU 阶段统计中独立显示，并计入增强总耗时。

启用的性能层依赖同段中先启用的普通 NR。节点图中的超分、调色和其他非 NR 处理断开该段。下游输出稳定器、保护区域和自动复用继续按效果链运行。

包含性能层的预设写入格式 v27，模式会话写入 v22，存放于 `.nr-residual-stack` 旁文件。现有官方预设及会话沿用原版本布局，旧版仍可读取原文件。导出主程序与子进程使用更新后的共享协议，覆盖叠层参数。
