# Veyra 2.1.1 本地待测完整包

本包使用Release配置，应用显示版本2.1.1、PE文件/产品版本2.1.1.0。由当前完成的采集审查分支构建，不等于已合main或已发布GitHub。

## 2.1.0以来的主要变更

- 处理后实时录制与音频生命周期修复；AMD关闭超分的状态修复。
- 极简/专业模式90°画面旋转与预览布局适配；旋转是当前预览能力，不新增录制/导出旋转承诺。
- 每层NR内部处理分辨率新增25%–100%手动比例；视频导出支持固定/百分比内部尺寸，最终导出尺寸保持所选输出尺寸。
- 修复补帧路径同步显示状态查询阻塞；VRR/刷新率/HDR改为共享事件触发查询，信号区提供刷新入口。HDR无缓存等待上限100ms，失败允许恢复。
- 列表模式空间抗锯齿移至NR组之后，避免后续NR覆盖AA效果；离线同帧GPU验证有实际变化，效果依素材而异。
- 截图提示等待实际编码完成，HDR截图报告真实JXR路径；全屏/最大化恢复与播放列表焦点修复。
- #67 NR/NVAPI关闭生命周期；采集卡无时间戳预备样本正常确认后跳过，不再向驱动返回失败，不伪造PTS。

## 测试方法

选择显卡对应的完整ZIP，完整解压到新目录，运行veyra_qml_ui.exe。不要只替换旧包EXE。旧包可保留作对照；程序依旧会读取原有用户设置，本轮打包/自动验收使用独立配置，不代改用户设置。

优先回归NR/抗锯齿开关、NR内部比例及视频导出、带音频录制、全屏恢复、旋转和HDR截图。遇到采集帧率异常，先关闭60→30、去重及增强，核对真实输入FPS；显示提交FPS不是物理屏幕实际显示FPS。

## 已知边界

- 外部用户4K YUY2约53fps及开启60→30后约26fps的问题本轮仅诊断，没有实现根因修复。
- CV710内置音频监听卡画面与3090关闭问题仍需原用户机器复测；本机通过不替代原硬件验收。
- 本机没有RX9000，AMD包启动/内容检查不等于AMD NR实际推理验证。长期显存增长尚未宣布根治。
- 实际VRR生效、屏幕端到端延迟、所有效果同时开启的实卡性能没有本轮新增验证。Lecram原生链接入仍暂停。
- 运行组件沿用2.1.0受控供体原件；社区/实验标记、许可证和哈希保留，清单不锁定用户自行替换兼容运行库。
