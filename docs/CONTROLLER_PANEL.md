# 手柄控制面板

采集卡、PS5 串流和 Xbox 串流的「手柄映射」按钮都会打开右侧面板。专业模式工具栏、全屏控制栏和极简胶囊里的手柄图标也能打开面板。键鼠已释放时可用 Ctrl+Alt+F1。

## 第一次设置

1. 在「连接」选 PS5 或 Xbox，配对或登录后选择主机。用采集卡看画面时，选择「只串流手柄」。
2. 在「方式」选实体手柄或键盘鼠标。用实体手柄时，键位和手感页会停用。
3. 在「键位」选步行或驾驶。直接点击手柄图上的按键、摇杆方向或组合键，即可录入主键。点击编辑卡里的「备用键」可另设一键。L3 + R3 和 Xbox 的 LS + RS 在图示右上角。Esc 取消，Backspace 清除。撞键时可选择迁移原绑定。点「试一试」可以在本地查看输入。
4. 在「手感」确认鼠标 DPI，再调灵敏度、横纵联动、平滑、反转和鼠标控制右摇杆。开镜、驾驶、曲线和校准可按需展开。
5. 点击「开始键鼠控制」。默认 F1 释放，F2 打开速查，F6 切换步行和驾驶。实际键位以当前档案为准。速查里的「编辑」会打开当前布局。

窗口足够宽时，视频让出右侧位置。窄窗中的面板可以收起成竖条。拖动左侧边缘可调整 380 至 520 逻辑像素的面板宽度。鼠标正在控制游戏时，按面板上显示的释放键恢复编辑。

## 实现约定

- 使用跟随主窗口的不透明 Qt 工具窗口。位置和尺寸一起更新。拖动左侧边缘时先预览宽度，松手后应用，视频区域只更新一次。
- 面板、游戏内提示和速查共用手柄图标、键帽与主题色。手柄图和列表同时呈现主键与备用键。交互控件使用可见的键盘焦点与读屏标签。
- 布局沿用现有档案 JSON。新建、改名、删除和保存由输入模块处理。改键保留旧手感与未识别的档案字段。键盘与鼠标录入取面板窗口，游戏模式仍对准视频窗口。
