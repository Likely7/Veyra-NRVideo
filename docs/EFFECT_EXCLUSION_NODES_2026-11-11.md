## 本轮范围

- 新增全效果剔除，矩形、圆形/椭圆、羽化。用户明确选择补帧也排除，遮罩内部保持原始源帧节奏。

- 输出稳定器作为可独立添加、启停和保存的节点，继续调用现有 NR Hold 实现。
- 现有 NR 列表设置和旧配置保持可读取，新增字段按版本保存，断流、seek、resize、暂停恢复清空时域状态。
- 实时、文件、截图和导出共享遮罩数据和 GPU 合成。图内生成帧以该时间段的原始 A 帧填回遮罩，真实 B 帧填回原始 B。XeSS 在呈现器中生成，需用其 UI 纹理通路保证遮罩图层不参与插帧。
- 当前按用户要求进行源码和静态检查，编译、GPU 和实际窗口验收另记实际结果。

## 实现

- 分支 `codex/effect-exclusion-nodes-20261111`，保留基线中的 Patreon 修改；未合并 main、推送或替换正式程序。
- 列表新增“全效果剔除”；节点提供独立“全效果剔除”“NR 保护区域”“NR 输出稳定器”。两种遮罩共用 MaskEditor，最多四个矩形/圆形/椭圆区域和 0–64 输出像素羽化，沿用原有旋转、缩放、平移坐标映射。
- 图内 DLSS/FSR/VFG 生成帧填回原始 A，真实 B 填回原始 B。未遮罩的增强历史单独保留；重置时只引用已初始化的当前原始帧。XeSS 使用现有 SDK 的 UI 合成接口，提供 UI 和 HUD-less 纹理；HDR10 两位 alpha 的 SDK 修正与时间相位须实际验收。
- 原始画面仍经过输入颜色解码、普通尺寸适配和显示转换；窗口几何、显示校准照常执行，不是原文件字节复制。NVIDIA App 等应用外驱动插帧不在软件控制范围内。
- 默认关闭，不分配遮罩纹理。开启增加有界 GPU 纹理和合成工作，纳入显存预算；不增加未来帧窗口、像素回读或逐帧 CPU 等待，不套用尚未验收的预热/异步计算组合。
- NR 保护不再被节点验证、添加菜单、模式切换、预设载入主动删除。稳定器调用现有 NR Hold，参数、启停、连线独立保存。NR 推理复用的原有列表模式准入限制保持。
- NR 关闭时稳定器不创建/读取无有效内容的残差历史；切模式、切预设、删除节点等结构变化取消尚未提交的绘制，避免画进另一个文档或重新创建已删除节点。
- 库版本 21、会话 16 使用 `.output-controls` 旁文件，保留旧文件；删除新节点后的编辑仍存该旁文件，避免重启读回旧状态。平面预设 37 保存新遮罩及两类遮罩的椭圆，导出 worker 协议升级到 15。
- 参数更新使用各自信号，滑条不触发整张节点图刷新，保留模型绑定。补充恢复节点、非法参数、保存/删除/重启、未连线参数等 C++ 用例，尚未执行。
