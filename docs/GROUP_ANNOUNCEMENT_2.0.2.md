Veyra 2.0.2 已发布，本次把 2.0.0 新功能和后续修复一起整理了：

• 全新界面：极简/专业模式、节点编辑、最多四层 NR、独立调色和新版导出队列，支持四种语言。
• 增加 PC（Sunshine/Moonlight）与实验性 Xbox 串流，与 PS5、采集卡共用增强链。
• NR 现在有三版可切换：50 系 NVIDIA 原版、Lecram、20–50 系 SF-v2，原有设置保留。
• 新增自动继续上次：设置中开启后，启动自动恢复视频及进度，或按上次配置打开采集卡；启动页可选极简/专业。
• 极简和专业模式都加入 1× / 1.5× / 2× / 3× 视频倍速，声音保调。
• 修复小飞机 RTSS 叠加导致的卡死/异常，默认自动兼容，监控数值只叠在视频上。
• 修复 Xbox 协商空值和断开时异常，补齐视频反馈；修正 VRR 采集输入反复清空补帧历史的问题。
• 包含导出遇到 GPU 重置后的断点恢复、抗闪烁关闭后画面定住、继续采集没声音、多层 NR 负载显示和调色效果等修复。

全屏显存异常自动退窗已改为设置开关，默认关闭。5060 Ti 显存增长根因仍未确认；Xbox 长时间稳定性和主机 VRR 采集效果请受影响的朋友继续反馈，不能保证所有设备都已解决。

下载只需一个压缩包，完整解压运行 veyra_qml_ui.exe。建议解压到新目录，保留旧版方便回退。小飞机和 OBS 游戏采集同时用时，在 RTSS 给 Veyra 开启 “Use Microsoft Detours API hooking”，或改用 OBS 窗口采集。
