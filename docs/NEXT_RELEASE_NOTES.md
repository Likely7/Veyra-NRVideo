# 下一版发布说明

采集占用恢复提示和重复启动唤起需要新版 Veyra 启动器。请下载完整安装包或完整便携包更新。应用内更新只替换版本目录，旧启动器遇到安装目录正在使用时仍会显示「正在运行或更新」。

## Next release

Capture recovery and reopening an existing window require the updated Veyra launcher. Update with the full installer or portable package. In-app updates replace the version directory. Older launchers still show “running or updating” when that installation is in use.
