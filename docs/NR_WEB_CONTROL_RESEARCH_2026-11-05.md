# NR 网状调节器：研究与三个候选方向

2026-11-05。用户要求研究交互思路；本轮不改 NR 界面或算法。

## 结论

可以借鉴网格上直接拖点、同时看见多个参数、保留参考形状的交互，但不能把达芬奇 Color Warper 原封不动套到 NR 上。Color Warper 的网格有连续的色相／饱和度坐标；NR 参数混合了模型输入、增强残差、颜色保护、时间域处理和运行设置，相邻点之间没有天然连续关系。

来源：[Blackmagic Design 官方 Color Warper 介绍](https://www.blackmagicdesign.com/products/davinciresolve/color)。这里的 NR 结论来自本仓库的 `NrLayerEditor.qml`、`NrSettings`、`ResidualSettings`、`NrCorrectionSettings`，不是上游工具的能力声明。

## 已核对的实际参数

| 类别 | 当前参数与范围 | 对新交互的约束 |
|---|---|---|
| 模型输入 | 强度／局部明暗／局部结构 0–1；肤质 -1 表示未指定，指定值 0–2 | 肤质效果未证实，不作为小白主轴；AMD 不开放 NVIDIA 风格控制 |
| 增强变化量 | 总量 0–5；暗化／亮化／色彩／明度 0–2，默认均为 1 | 总量是乘法控制，必须区别于单项；0 是取消对应变化，不是图像变黑 |
| 手动画面调控 | 色相／色度／中性／原色保留／亮度保留／暗部／高光／局部压缩／时域稳定，各 0–1 | 仅开启调控且使用手动时生效；增加保护通常减少对应 NR 改动，不代表画质必然提高 |
| 自动调控 | 按风格 0／1／2 生成保护值，力度 0–1 | 自动状态不能展示旧的手动值并假装在操作实际输出 |
| 时间域 | 另有防闪烁开关与算法档位；调控开启时由调控接管稳定性 | 暂停画面不能验收运动稳定性，不能与旧防闪烁重复叠加 |
| 运行设置 | 模型版本、性能模型、内部尺寸、运动来源、处理顺序 | 不放入画面风格网；这些会改变能力／资源／历史状态，部分会重建管线 |

## 三个候选方向

### A：分组直接调节，优先建议

一处打开 NR 面板，参数不必逐项展开。保留“变化／保护／模型”三个固定页签，页内主要控件同时可见。

- **变化网**：四个方向是暗化、亮化、色彩、明度，直接对应现有四个 0–2 参数。默认 1 位于中圈；中心 0，外圈 2。总变化量 0–5 独立放在网下，标清“整体倍率”，防止总量与单项看似重复。
- **保护网**：先展示原色保留、亮度保持、暗部保护、高光保护、局部压缩、时域稳定六轴。色相、色度、中性色保护在同页下方直接显示精细控件。默认值不同，使用各轴默认标记与虚线默认多边形，不伪造一条共同的默认圆环。
- **模型页**：强度、局部明暗、局部结构直接显示；风格和未证实项目保持明确标签。AMD 只展示实际可用项，不画假控制点。

优点：没有隐藏的多参数映射，旧预设逐值可逆，能与专业数值控件完全同步。局限：仍需要解释“暗化变化”和“保护”的作用；蜘蛛网本身不会消除概念学习。应以一句话效果提示、默认参照和画面对比补足。

### B：单张完整参数网，适合熟悉参数的人

同一张网按模型／变化／保护划成三个扇区，所有有效参数都可见；按轴径向拖动，中心显示当前参数说明和数值。

优点：一眼看全。问题：轴太密、范围不一致、弱相关参数的连线会暗示不存在的关系，窄侧栏很难操作。不建议作为小白默认入口；最多是专业模式全屏调参面板。

### C：画面意图网，长期候选

主轴使用“保留颜色、保留明暗、控制暗部、控制高光、纹理改动、运动稳定”等结果语言，一个点可以影响多个底层参数。

其中前四项已有直接参数可用；“纹理改动”不能直接把局部结构／残差总量当成通用锐度，“运动稳定”也需要播放中验收。多参数轴必须先用真人、动画、低码率、HDR、运动等素材标定，公布映射与冲突规则，再谈容易使用。当前不能承诺拖一个“细节”点就能稳定改善所有素材。

优点：学习门槛可能最低。代价：新增产品行为及验证工作，映射不当会把参数复杂度藏起来。尚不是可以直接落地的已验证算法。

## 推荐交互细节

1. 点只沿自己的轴拖动；任意拖网面、自动拉动邻点不作默认行为，因为 NR 轴间没有几何插值合同。
2. 点命中区至少 24–28 个逻辑像素；按下锁定轴，拖出面板仍可完成或取消；Esc 回滚本次拖动。
3. 拖动时显示原值、当前值和一句具体影响，例如“向外：增加 NR 带来的颜色变化”；不使用“越大越好”的面积或评分。
4. 默认虚线与本次打开面板的原形都能参照；双击单点恢复该参数默认值，整组恢复单独操作。保留数字输入、方向键微调及撤销。
5. 自动保护开启时显示实际派生形状并只读；用户选择手动后先采用当前自动参数，再编辑，避免突然跳变。切换前明确其会覆盖手动值，现有手动值应可撤销恢复。
6. 提供当前层开／关对比、冻结画面比较与播放比较；冻结只适合空间效果，稳定性要看运动。多层 NR 明确正在编辑哪层。
7. 所有操作仍复用 `edited(index,key,value)` 与现有保存结构；运行设置不因拖点反复重建。新网与数值控件读取同一份设置。
8. 不用渐变彩虹暗示这是颜色取样器；本设计不选取某种颜色或某个物体。若要在画面中吸色后局部调整 NR，那是额外的遮罩／选择性合成功能，需要另行设计。

## 实施前验收门槛

- 旧预设读入后，网与数值逐值一致；范围、未指定值、AMD 能力差异和自动／手动状态正确。
- 鼠标、触控、缩放、拖出控件、Esc、回车、失焦、单点／整组恢复、层切换与撤销均无误提交。
- 列表与节点页共用组件，不复制两套参数映射；保存、重启、图片与视频导出读到相同参数。
- 拖点没有额外 CPU/GPU 回读、无界更新或模型重建；重复修改历史型参数遵守现有 reset 合同。
- 用小白完成“减弱偏色、保留暗部、减少闪烁”三个任务，比现有滑条更易找到且能理解结果，才算交互收益；不能只凭外观验收。

建议先选 A 做静态交互草图，再决定是否开发。本文不授权恢复任何已撤销实验。
