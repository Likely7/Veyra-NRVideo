## 已完成的实现

- `NrLayerEditor` 只管理控制器开关与输入归属；`NrParameterEditor` 保留整套原控件，并供两种控制器共同使用，防止参数清单分叉。
- `NrWebControls` 组合两张网、总强度与本层旁路对比，其他项目仍在同一面板内；原有组默认展开。`NrWebPad` 提供轴向拖动、点标签选择、数值输入／键盘、默认虚线、恢复默认、单步撤销与Esc回滚。
- 开关保存为已有JSON偏好中的 `nrWebEditor`，默认false，不进入增强设置／预设／导出协议；其余编辑仍调用既有接口，两个编辑器没有独立参数副本。
- 自动网的六个值来自 `NrCorrectionSettings::constants()` 同一结果；只在桥接返回字段，不变更计算。切手动依旧恢复保存的手动值，不隐式覆盖。
- 所有原控件及AMD条件保留。原列表禁用时也阻断其迟到的参数信号。拖动取消、禁用、层变化会停止定时提交；数字滑条同样检查交互所属层，拒绝迟到更新。
- 标签适配窄侧栏与多语言，颜色跟随既有主题；没有新增淡入淡出。
