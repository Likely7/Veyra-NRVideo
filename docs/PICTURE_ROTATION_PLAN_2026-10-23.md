# 画面手动旋转

用户要求极简/专业模式小按钮，每次顺时针90°，画面旋转后界面适配。继承上一轮 AMD关闭/录制已验源码4eee190，在同一干净E盘工作树切codex/picture-rotation-20261023；起点标签checkpoint/pre-picture-rotation-20261023。其它工作树和待提交全屏修复保持，不合main/push/发布。

复用PreviewView、PresentBlit、XeSS既有元数据旋转和输入映射，只增加独立会话级手动偏移，不改处理/解码/增强纹理坐标。现有旋转接口的必要engine/header/bridge/QML接点由本次用户功能请求覆盖旧UI冻结；本轮不是旧无人值守UI迁移，固定旧桌面/旧分支的migration-scope-guard不适用，不修改guard或其基线来制造通过。专有运行库/模型/驱动及真实配置保持。

两模式及全屏共用RotateButton；4次恢复、关闭后新源清零，模式/全屏/暂停/seek不清零；旋转时重置缩放和平移并取消未完成选区。DAR仅叠加手动旋转，不重复应用元数据；固定比例也随手动旋转转为纵向。极简窗口按旋转后比例适配，控件保持正向；专业模式保持布局并适配预览。游戏模式旋转时沿用已有非1:1预览的键盘/手柄策略，拦截错位鼠标穿透。

验收：所有元数据方向×4次手动旋转×7显示模式的比例/坐标与滚轮锚定契约；实际D3D12着色器色块像素；真实播放器桥接/两按钮/窗口比例/全屏/暂停/切源/录制回归；四语言、QtQuick和既有UI/修复契约。只声称通过的具体场景，不承诺绝无bug。全E盘codex-picture-rotation-20261023目录；复用build/claude-screen-recording-20261022（同源路径），-j2≤900秒，单测试≤300秒，单Agent。日志和未验项追加WORKLOG与报告。
