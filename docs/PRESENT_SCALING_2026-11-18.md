# 全屏发糊/像素化：送显缩放改为高质量（2026-11-18/19）

多位用户反馈"全屏之后很糊、像素化"。用户要求：必须直接输出最高规格画面。

## 原因

画面最后一步由 `PresentBlit.hlsl` 把处理结果（工作尺寸）画到交换链（窗口客户区的物理像素；全屏即显示器分辨率，高 DPI 下也是物理像素，已核对 `syncVideoGeometry`/`GetClientRect`）。

此前只有 PS5 远程游玩（`isRemote && reconstructChroma`）打开"精细采样"，其他所有来源（采集卡、屏幕捕获、文件、图片）都用一次硬件双线性采样：

- **放大**（如 1080p 采集在 1440p/4K 屏全屏）：双线性只看 2×2 像素，画面整体发软。
- **缩小**（如 4K 采集或超分到 4K 后在 1440p/1080p 屏全屏，或放在窗口里）：双线性每个屏幕像素只取 2×2 源像素，其余源像素被跳过，细节锯齿、闪烁，看起来"像素化"。原 PS5 精细路径在缩小时也退回双线性。

## 修改

- `EngineController::run`：所有来源 `highQualityPresentation=true`；大图预览（`runLargeImage`）同样打开。测试用环境变量 `VEYRA_TEST_PRESENT_BILINEAR=1` 恢复旧双线性，用于 A/B 对比。
- `PresentBlit.hlsl` 精细路径：
  - 1:1 且像素对齐：逐像素原样拷贝（与旧版一致，HDR/颜色检查依赖它）。
  - 放大：保持原 PS5 路径的 Catmull-Rom 4×4，限制在相邻 2×2 范围内防振铃。
  - 缩小（新增）：Catmull-Rom 按缩小倍数加宽（每个轴各自计算，四分之一旋转时轴向互换），权重归一化，在工作帧自身编码中计算（SDR 输出是 sRGB 码值，scRGB HDR 是线性光，HDR10 是 PQ 码值；图输出格式见 `EnhanceGraph::outputFormat()`）。
    - ≤2:1：每轴 4 个配对采样，共 16 次取样；每对只配同一瓣内的两个像素，由硬件双线性一次混合，结果与逐像素卷积一致（误差仅为硬件 8 位插值分数）。
    - 2:1–4:1：同样的配对方式，64 次取样。
    - >4:1（大画面放进很小的窗口）：采样点跨度大、缓存命中差，改用 16 次取样、核宽封顶 2:1，耗时有界（仍有滤波，远好于旧双线性）。
    - HDR 防振铃：任一取样值 >1.0（scRGB 线性 HDR，1.0=80 尼特）时，结果限制在正瓣样本的取值范围内，避免极亮高光旁出现暗圈；SDR 范围画面和 PQ 码值（≤1.0）保持完整 Catmull-Rom 锐度。
- 核函数选择：在真实 GTA 画面上对比，Mitchell 缩小后高频比旧双线性还低（2.69 vs 3.03，更糊），Catmull-Rom 3.12 接近 Lanczos-2/3 而负瓣更小，采用 Catmull-Rom。
- 虚拟摄像机的转换着色器跟随同一标志：非 1:1 时从双线性变为它已有的有界三次插值（原 PS5 行为），未加宽缩小。

## 验证（RTX 5070，本机）

新测试 `veyra_present_scaling_tests`（`tests/integration/PresentScalingGpuTests.cpp`）离屏运行真实 `PresentBlit` 着色器，与 CPU 模型逐像素对照：

| 检查 | 结果 |
|---|---|
| 1:1 2560×1440 | 与源逐像素相同（最大差 0） |
| 放大 1080p→1440p / 1080p→4K / 720p→1440p | 与 Catmull-Rom 模型最大差 ≤0.00077 |
| 缩小 4K→1440p / 4K→1080p / 4K→720p / 4K→360p / 1440p→1080p | 最大差 ≤0.0046（旧双线性自身对模型也是 0.0045，同为硬件插值精度） |
| 黑边 1080p→2560×1600 | 黑边严格为不透明黑 |
| 四分之一旋转 | 与模型一致 |
| HDR 亮块（100.0 在 0.2 背景上） | 4 个尺寸最小 0.1998、最大 100.0，无暗圈（未防振铃时会到负值） |
| 波带片与 Lanczos-3 参考的均方根误差 | 旧 0.077–0.098 → 新 0.030–0.043，接近 2.1–2.5 倍 |
| 真实 GTA 帧 1080p→1440p 与原生 1440p 渲染 | PSNR 44.62 → 46.91 dB；车牌文字明显更锐 |

每次送显 GPU 耗时（旧→新，ms）：4K 1:1 0.109→0.116；1440p 1:1 0.059→0.037；1080p→1440p 0.060→0.095；1080p→4K 0.085→0.262；1440p→4K 0.109→0.270；720p→1440p 0.041→0.131；4K→1440p 0.044→0.295；4K→1080p 0.040→0.154；1440p→1080p 0.020→0.119；4K→720p 0.086→0.338；4K→360p 0.005→0.171。补帧时每张输出帧各算一次。

真实 `VideoPresenter` 回归：`veyra_preview_geometry_tests` 新增 `--fine`，适配、缩放、平移、对比参考、90/180/270 旋转、拉伸、原生、DAR、窗口改尺寸保留缓冲等 23 项，旧模式与精细模式均 23/23。虚拟摄像机 GPU 523/0。
