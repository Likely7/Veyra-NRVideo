# Veyra 2.0.0 — 本地稳定性测试包

本包使用正式版本号 2.0.0，从 main `aafdeb061e45ae8cdaebfaf68e16c3d589771c05` 全量构建；包含当前主线的 QML 界面、多语言、导出队列、多音轨/字幕、PC 与 Xbox 串流等功能。没有加入已取消的游戏加加 / RTSS 适配改动，没有公开发布。

## 运行

1. 完整解压到新的可写目录，运行 **veyra_qml_ui.exe**。不要覆盖旧版本；不需要安装 Qt、SDK 或开发工具。
2. 先保持增强效果关闭，确认文件或采集卡的画面、声音，再逐项开启 NR、超分、补帧。
3. 本版设置与旧版分开保存。PS5、PC、Xbox 的配对或登录身份不随便携包分发；不要把自己的配置、账号目录再打进分享包。

## 稳定性测试建议

按实际日常素材连续播放，分别试效果全关、NR、超分和常用补帧方式；反复暂停/继续、拖进度、切全屏、换片源。关注显存是否持续上涨、音画是否逐渐偏移，以及关闭程序能否正常退出。

再试导出队列、取消后重试、MP4/MKV 音轨和字幕；采集卡及 PS5/PC/Xbox 串流需要对应设备实测。出现异常时记录时间、显卡/驱动、素材规格和开关组合，保留 `logs/veyra-qml.log` 及同目录的 `veyra-crash-*.dmp`。日志和转储可能包含本机路径，不自动上传。

## 已知边界

- **RTSS / 游戏加加注入兼容问题未修复。** 本机已见 RTSS 下打开视频时设备丢失；D3D11 界面对照在 XeSS 下崩溃。测试本包时请关闭它们对 Veyra 的注入；这不代表适配已完成。
- 历史反馈的 RTX 4070S NR TDR、部分 5060 Ti 显存增长没有在本轮修复。短测通过不代表长时间、所有显卡或所有采集设备稳定。
- 社区 NR、补帧优化内核、30/40 系兼容、FSR 4 ML 和串流仍保留各自的实验边界。版本号 2.0.0 不代表 NVIDIA/Intel/AMD/Microsoft 官方认证。
- 组件页的“已加载”来自静态清单，不能替代实际启用日志。逐文件身份见 `release-runtime-manifest.json`；它是发行者审计清单，不限制用户自行替换运行库。
- 随附 `veyra-source.zip` 仅是本次 Veyra 源码快照；公开分发前仍需补齐新增依赖的完整对应源码和构建材料。本轮没有公开上传。

自动回归与实际运行结果另附 `STABILITY_REPORT.md`。未测试的项目不会写成通过。

## 本次更新：OBS 兼容与新图标

设置 → 通用与外观新增“OBS 游戏采集兼容”（默认关闭）。修改立即保存；需要切换当前绘制模式时弹出“需要重启软件”，选“是”正常退出并重新启动，选“否”保留当前会话、下次启动生效。重启会停止当前播放/串流；正在导出时请等导出完成再重启。

兼容模式以软件绘制 UI，部分阴影/模糊简化，D3D12 视频与 NR/SR/FG 保持原路径。OBS 游戏采集针对视频，录完整界面请使用 Windows 10 (1903+) 窗口采集。用户已确认此前候选有效；四种增强组合合计 720 次缩放短测通过，不代表长期或跨硬件全部稳定。

本包整合圆角渐变黑底新 EXE 图标及 Qt 窗口/任务栏图标。源码基于上述 main 加本地隔离修复，不是未修改的 main 快照。未公开发布。
