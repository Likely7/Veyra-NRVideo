## 未验与已知限制

- 本轮未实际启用 DLSS/XeSS/FSR 补帧，没有完成它们的长时共存/稳定性测试；超分、HDR 实屏、听音和屏幕端到端延迟也不由上述结果证明。
- RTSS/GamePP 注入未修复。实际验证进程没有载入它们；既有 NVIDIA 叠加模块仍在。测试本包请关闭 RTSS/GamePP 对 Veyra 的注入。
- 历史 NR TDR、部分设备显存增长，以及真实采集卡、PS5/Sunshine/Xbox、30/40 系与 AMD/Intel 实机仍需各自验收。
- windeployqt 提示找不到 dxcompiler/dxil DLL；本轮 D3D12 界面和 NR 实際播放已通过，但不能外推所有驱动环境。
- 源码 ZIP 是 Veyra 源码/打包材料快照，非完整第三方依赖对应源码集合。公开分发前需补齐新增依赖源码；本轮仅本地交付。
