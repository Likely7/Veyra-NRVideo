## 改动

- **导出跨设备重置续导**：`VideoExportJob` 在 GPU 被重置时不再整段失败：不让死设备排空，把已收到的编码包、音频写完并写索引，得到合法的分段文件，报告"从源时间 X 接着导"（取最后写入帧后半帧，不会因舍入多跳或重复一帧）；导出进程以退出码 4 结束。`ExportJobManager` 收到后保留分段、沿用同一个任务编号重新启动导出进程（最多 3 次续导、4 段）；最后一个进程完成自己那段后用 `joinExportSegments` 逐包复制拼接（按各段首帧源时间平移时间戳，丢弃接缝处不前进的包，要求轨道与视频参数集一致，否则保留各段并说明），成功后删除分段。取消会删除全部分段。共享内存版本 6→7。测试钩子 `VEYRA_TEST_EXPORT_REMOVE_DEVICE_AT=<帧>`（只在第一段进程生效，调用 `ID3D12Device5::RemoveDevice`）。
- **爆显存**：检测到 `nvppex.dll` / `NvPresent64.dll` 时，看门狗不再做重建（现场证明释放不了、还会闪屏），提示到 NVIDIA App 为 Veyra 关闭 RTX HDR / 智能平滑运动 / 动态鲜艳度；`overlay-hooks` 记录 nvppex 何时注入。
- **Xbox**：日志写出完整 offer / answer SDP（offer 不含候选地址），配合更新包里已修的空字段处理，下一份日志能看到主机的拒绝原因。
- 版本 2.0.1（数据目录仍为 `user-data-2.0.0`，设置不丢）；打包脚本接受 2.0.x，发行说明按版本取，运行库锁沿用 2.0.0（运行库未变）。
