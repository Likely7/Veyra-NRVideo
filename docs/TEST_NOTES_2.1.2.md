# Veyra 2.1.2 本地测试版

本包整合当前 main 上从2.1.1发布后完成的功能和修复，含Claude与Codex的工作。尚未发布到GitHub。

## 本次内容

- 真正双重超分：基础超分后降低第一次的结果，再第二次超分，独立展开第二组参数；普通单次8K保持原有能力。
- 超采样“超分后缩回到”：较高尺寸超分后线性光缩回，后续NR/补帧按最终尺寸运行。
- 英伟达低延迟：关、开、开＋增强；保留各补帧提供方的调度归属。
- RX7000 NR实验路径：RedDuke Small/Original独立worker，兼容每层内部百分比；RX9000仍走lmxxf。
- 实时补帧呈现锚点平滑、VFG自动调控开关及“自动剔除重复帧”名称调整。
- 自适应垂直同步容量等待：抖动较大时适当多等，上限3ms；普通自动/允许撕裂保持原路径。自动＋VRR若走垂直同步队列也受此规则约束。
- 屏幕采集无补帧时就绪即呈现、捕获帧率、采集载波Dolby/DTS、F7/F8、60→30取第一份等已合入的修复。
- 极简音量：修复快速拖动、0%/100%起拖、输入焦点、回车/数字键盘Enter及点击空白提交，Esc取消；音量操作不触发窗口移动。

## 启动与设置

1. 根据实际用于Veyra的显卡选择NVIDIA或AMD包，完整解压到新文件夹，运行 `veyra_qml_ui.exe`。
2. 本包不包含你的配置、登录信息和测试媒体，首次效果默认关闭。建议先用干净设置验收；要迁移已有设置，先关闭两边程序，再复制旧包的 `runtime_local/user-data-2.0.0`；自定义LUT另复制 `runtime_local/luts`。
3. 建议新目录解压，避免旧DLL/缓存留在目录里使测试结果混杂；保留旧版便于对照。
4. AMD包同时提供7000/9000两条NR实验路径。RX7000选择实际AMD显卡，先以1080p内部尺寸和Small测试；需要目标机已有可用HIP7驱动组件。本机测试不能替代RX7000实卡验证。

## 验收口径

应用显示的提交FPS不是屏幕物理刷新次数；补帧和显示延迟分别看实际采集卡与显示器表现。2.1.2回归结果、构建源码快照和完整组件身份在 `package-manifest.json`、`release-runtime-manifest.json` 及开发测试回执中记录。此本地测试包不代表所有显卡或长时间稳定性验收。
