# Veyra 2.1.3 本地测试版

## 本次更新（相对2.1.2）

- NR增强变化量、画面调控手动设置，各自可选择网状或列表。变化四轴搭配总量滑条，手动画面调控保留全部九项；数值、撤销、默认及原参数保存共用。
- 修复软件绘制下弹出菜单文字来回跳1像素；保留原动画风格，GPU绘制不变。
- 修复全屏进度条拖动被取消。
- NVENC导出H.264/HEVC周期IDR与GOP同步，恢复文件的随机跳转索引。
- RTX30 VFG实验兼容；RTX40/50保留原生路径。
- RX7000 NR多GPU身份匹配与HIP设备选择修复，补齐worker诊断。
- RTX视频超分分为标准、高码率、流媒体；档位低/中/高/超高，流媒体提供中/超高。双重超分第二次可以独立选版本和档位，兼容超采样。
- 英伟达低延迟增强档增加高负载掉帧提示。

## 使用

按显卡选择NVIDIA或AMD包，完整解压到新目录，运行veyra_qml_ui.exe。首次效果默认关闭，包内没有个人配置。
迁移设置先完全退出旧版和新版，再复制旧目录runtime_local/user-data-2.0.0；自定义LUT另复制runtime_local/luts。保留旧目录以便对照。附带测试启动脚本使用独立配置；要验收迁移设置则直接打开解压目录中的EXE。
高码率/流媒体仅放大，同尺寸增强用标准。新模型第一次初始化可能较慢。RTX30 VFG、AMD NR仍按实际显卡验证，不保证所有型号的性能或稳定性。
包身份和组件见package-manifest.json、release-runtime-manifest.json；构建与测试见docs/BUILD_2.1.3_TEST_2026-11-06.md。本次只供本地测试，未发布GitHub。
