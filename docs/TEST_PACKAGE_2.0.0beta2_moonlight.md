# Veyra 2.0.0 beta 2（含 PC 串流 · Moonlight）测试说明

本包在 2.0.0 beta 的基础上新增**PC 串流**：把另一台电脑（装了 Sunshine 的主机）的画面串流到本机播放，
再交给软件自己的降噪、超分、补帧和调色。**这是第一次接入，只在没有真实主机的情况下做过离线测试，
请有两台电脑的测试者重点验证。**其余功能与 2.0.0 beta 相同，见同目录 `RELEASE_NOTES.md`。

新界面程序是 `veyra_qml_ui.exe`，整个文件夹可拷到别的电脑运行，设置和日志都在这个文件夹里。
PC 串流的主机列表、设置和配对身份存在 `%LOCALAPPDATA%\Veyra\moonlight\`（身份文件用 Windows DPAPI 加密）。

## 准备（两台电脑）

1. **被串流的电脑（主机）**：安装 [Sunshine](https://app.lizardbyte.dev/Sunshine)（本软件不自带，也不代为下载）。
   显卡需要能硬件编码（NVIDIA / AMD / Intel 均可）。在 Sunshine 网页（`https://主机IP:47990`）里确认有「Desktop」或游戏条目。
2. **播放的电脑（本机）**：两台电脑在同一个局域网，最好有线。主机防火墙放行 Sunshine（安装时默认处理）。
3. 打开本软件 → 首页 **「PC 串流」** 卡（或专业/节点页的片源菜单 → PC 串流…）。

## 测试步骤

1. 主机应自动出现在列表里（没有就在「手动添加」填它的 IP）。状态为「未配对」。
2. 点「配对」：软件显示 4 位 PIN；到主机的 Sunshine 网页 → **PIN** 页，输入这个 PIN 并提交。成功后出现游戏列表。
3. 选「Desktop」或一个游戏，点「开始串流」。先用默认设置（1080p · 60 fps · 自动码率 · 自动编码）。
4. 连上后：画面是否出现、声音是否正常、键盘鼠标是否在主机上生效（连上后键鼠会自动交给主机）、手柄是否可用、手柄震动是否回传。
5. 键盘鼠标被主机占用时：**Ctrl+Alt+Shift+Z 释放**，点击画面重新捕获，**Ctrl+Alt+Shift+Q 断开**，**Ctrl+Alt+Shift+S** 显示/隐藏统计浮层。
6. 在专业页打开 NR / 超分 / 补帧，看串流画面能否正常增强（补帧默认是关的，和其它片源一样由你打开）。
7. 再试：4K · 60 fps（码率调到 80 Mbps 以上）、HEVC、HDR（主机显示器需开 HDR，编码选 HEVC 或 AV1）、5.1 声道、断开后再「继续」同一个游戏。
8. 局域网内故意拔网线几秒再接上，看是否报错、是否能重连（**重连还没有做，预期是报「连接中断」，请记录现象**）。

## 请重点记录

- 能否连上、从点「开始串流」到出画面要几秒；
- 延迟感受（画面里的鼠标移动、按键反应）；统计浮层里的「主机 / 往返 / 接收 / 排队 / 解码」各几毫秒；
- 4K60 是否稳定，FEC「未恢复」包数和丢帧数是否持续增长；
- HDR 颜色是否正确（和主机屏幕对比）；
- 任何崩溃、卡死、花屏、声音断续。

## 反馈时请附上

- 主机：显卡型号、Sunshine 版本、编码器（Sunshine 网页里看）；本机：显卡、驱动、Windows 版本；
- `logs\veyra-qml.log`（出问题后先退出软件再拷，搜 `moonlight`）；
- 统计浮层截图或录屏。

## 已知情况与限制

- **未在真实 Sunshine 上验证过任何串流**：连接、画面、声音、输入、HDR、4K60 都是未知数，这正是本次要测的。
  离线只验证了协议解析、配对、界面流程和输入转换。
- 设备名以「Veyra」向主机报到；若某个主机拒绝配对或在它的已配对列表里显示异常，请告诉我主机软件和版本。
- 没有做：断线自动重连、陀螺仪与触摸板、多手柄、扳机震动、游戏封面图、Windows 键/Alt+Tab 的捕获（这些仍归系统）。
- 解码用硬件（D3D12VA）；不支持时退回软件解码，软件解码只输出 8 位，HDR 需要硬解。
- AV1 只在你明确选择时才使用；「自动」只在 HEVC 与 H.264 之间选。
- 「让主机切换到串流分辨率」默认关：主机保持自己的分辨率，画面由主机缩放。
- 补帧优化内核和社区 NR 运行库仍是实验组件，见 2.0.0 beta 说明；仅供内部测试，请勿外传。
