# 界面与切换问题修复（2026-10-01，beta 6）

来源：用户在本机用 beta 5 试用后的 7 条反馈（截图 + `logs\veyra-qml.log`）。

| # | 反馈 | 原因 | 修改 |
|---|------|------|------|
| 1 | 极简模式播放条空白处按住要能拖动窗口 | 播放条是独立的小窗口，没有处理拖动 | `CineBar.qml` 加 DragHandler（只在窗口化极简模式生效），按钮、进度条、音量条照常；拖动交给系统移动主窗口（`startSystemMove`，和顶栏胶囊一样） |
| 2 | 全屏时点顶栏「专业模式」进不去 | 全屏只显示画面，换页后页面不显示，看起来没反应 | 全屏时从顶栏换到别的页，先退出全屏再换页（播放条菜单本来就是这样） |
| 3 | 专业模式 GPU 阶段耗时条 0 / 5.8 / 0 / 5.8 来回跳 | 条的列表每次刷新（每秒 4 次）都是新数组，Repeater 整组重建，每根条都从 0 重新动画 | Repeater 改用条数做模型，每行按序号读当前值；条只在数值变化时平滑过渡 |
| 4 | 负载预算百分比不准 | 实际显示的是"输出帧率 / 目标帧率"，只要不掉帧就是 100%；设计时定的是"耗时 / 预算" | 改为增强链 GPU 耗时 P95 占一个源帧时间的比例（例：30 fps、NR 3.8 ms → 11%）；超过 100% 表示跟不上源帧率。掉帧状态仍看下方状态灯 |
| 5 | 先开采集卡再连 PS5，软件像卡住，有声音，过一会才出画面 | 日志：第一次连 PS5 主机 20 秒没连上（`connected=false`），这期间视频窗口一直留着采集卡最后一帧（采集卡接的正是 PS5，所以看起来像 PS5 画面卡住）；PS5 连接没清掉上一次的会话号，"连接中"状态提前结束；再点连接时，没连上的旧会话又花了 18 秒才关掉 | 新片源打开期间，视频窗口的显示区域清空，露出黑底和"正在连接 PS5"提示，新画面出来后恢复；PS5 / PC / Xbox 三种串流连接都清掉旧会话号；引擎读当前串流会话改为在锁内取指针（原来与关闭过程有竞争） |
| 6 | 极简模式什么都没打开时，点画面要弹出片源菜单 | 没有这个入口 | 空画面上点一下，在点击位置弹出片源菜单（与专业页「片源」按钮相同）；提示文字改为"点击画面选择片源" |
| 7 | 屏幕捕获竖屏窗口、打开竖屏视频，窗口超出屏幕 | 极简模式窗口高度 = 宽度 ÷ 画面比例，没有上限 | 画面高度不超过屏幕可用高度（留出播放条 46 px）；放不下时窗口变窄并保持居中，底部超出时上移；之后打开横屏片源或离开极简模式，宽度恢复。极简模式最小宽度 360（顶栏约 330 宽）；播放条至少 760 宽，竖屏时可以比画面宽，并保持在屏幕内 |

- 新增 `scripts/ui-check/ui-check.py` + `field-ui-20261001.qml`：用真实程序跑一遍，真实鼠标点击和拖动，截图在 `E:\项目\Veyra\tests\ui-fixes-20261001\run5\`，结果 PASS：
  - 空画面点击 → 片源菜单打开（02）；

  - 拖播放条空白处 −160 px → 窗口移动 −144 px（前 10 px 左右是拖动起步阈值）（04）；
