## 五、方案

**X 类（bug）**
- X1：`DLayer`/`VConfirm`/`VMenu` 增加 `property bool videoCover: true`，`main.cpp collectCovers` 改为按该属性（兼容旧 objectName）识别，弹窗各自的 objectName 保留给测试。
- X2：补帧方式下拉显示所选项的中文标签。X3：确认框文案改为“首次进入节点配置为空白画布”。
- X4：进入极简前记住窗口高度，离开极简（非全屏/最大化）恢复。
- X5：先实测（缩略图排在 13 张胶片之后异步加载）；若只是加载顺序，当前项缩略图改为先请求、胶片延后。
- X6：窗口模式 2.39 片复核字幕与播放条；若重叠，字幕抬升改为按播放条实际压入画面的高度。

**M1**：缩略图服务新增封面：读取文件的附图（MP4 `attached_pic`、MKV 图片附件），有则播放条左侧显示，没有保持黑色。

**弹窗**
- D1 采集卡：顶部预览区（有画面时每 2 秒用现有截帧存一张小预览图；无画面时为黑底提示）+ 信号状态行（信号正常/恢复中/未连接 · 分辨率 · fps · 格式）；刷新改为图标按钮；底部提示“关闭其他占用同一采集卡的软件”；主按钮加播放图标。
- D4 字幕：顶部实时预览（当前画面缩略图或暗色底 + 示例字幕，随字号/字体/描边/背景条/底部距离实时变化）；延时改为 − 数值 + 步进器（±50 ms，Shift ±1 s，数值可直接输入）；增加“恢复默认”。
- D5 另存预设：名称置顶并实时提示重名/空名；中间按设计稿逐条列出将保存的效果及参数（绿点 = 启用，灰 = 已关闭）；下方“选项”保留现有的效果链/色彩/补帧/声音勾选与“保存后设为启动默认”。
- D6 切换确认：列表模式 / 节点模式两张对比卡 + 三条要点；切回列表同样改为要点列表。
- D7 管理预设：行内图标按钮（设为启动默认/复制/删除）、“启动默认”橙色标签、页签旁导入/导出；删除行收拢动画。删除四个内置预设：`PresetLibrary` 增加“不含内置预设”开关，仅新界面使用（旧 Win32 行为不变），载入时移除旧文件中带内置标记的条目，启动默认指向内置时清空。导入/导出：`PresetLibrary` 增加单个预设导出为文件、从文件导入（重名自动加后缀）。

**专业页**
- P1 顶栏：片源按钮显示“文件名 / 采集卡 · 设备名 / PS5 / 屏幕 · 目标”+ 下拉箭头；格式标签显示“1080p60 · 格式 · 色彩”；列表/节点与预设按钮加图标。
- P2 视频下方：“源 1080p60”“输出 3840×2160”带文字标签，补帧开启时橙色倍率标签（关闭显示“补帧关”）。
- P3 NR：一张“NR 画面增强 · N 层依次处理”父卡（层数指示条），各层卡片嵌入其中，“添加 NR 层”在卡内。
- P4 补帧页：去掉“处理顺序”块；补帧总卡（开关 + “始终在所有画质效果之后”）；“光流 · 运动估算”“显示同步与输出上限”两个可折叠小组（带项数）。
- P5 色彩页：顶部卡片含撤销/重做/复制/粘贴图标（bridge 新增调色历史与剪贴板，拖动滑条合并为一步）、“按住看原图”按钮样式、“一键还原”；中心型滑条从中点向两侧填色。

**导出**
- E1 左栏改为队列列表：每项缩略图（当前文件用播放源，其他文件用缩略图服务按路径解码）、名称、格式/时长、状态与进度条（bridge 按输出路径跟踪队列项）。
- E2 输出设置行的标签列加宽、说明换行不再挤成多行。
- E3 “视频 / 图片”类型切换；保存路径显示为输入框样式 + 文件夹图标；底部“预计耗时 · 大小”（导出中按进度推算，开始前只显示大小）；开始导出按钮加图标。
- E4 分屏对比时左右角标“原画 / 增强后（预览）”。

**设置**：S1 导航图标；S2 强调色色块、默认页面分段、语言下拉（仅简体中文）；S3 内容限宽 720px。

**节点**：N1 卡片头按类型着色（调色 #E0C341、超分 #4F7BFF、NR #FF8A3D、保护 #8A8A96、HDR #FFB547、补帧 #3DDC84，渐变）；N2 调色节点改为可折叠分组列表（亮 6 项…，点开组内调参）；N3 顶栏加片源下拉、列表/节点分段、节点预设下拉（保留播放按钮）。

**动效**：A27 GPU 条逐条错峰 800 ms；A30 参数卡新增弹出（scale .85/y-8，600 ms spring）与删除（scale .9，300 ms）；A31 页签内容逐项浮现（460 ms，每项 30 ms，y10）；A32 设置分区逐项浮现（480 ms，每项 40 ms，y12）；A33 节点新增（scale .6，600 ms）/删除（scale .7）；A37 混色器色块 22px、圆角 7、选中 1.08、400 ms spring；A38 新增转圈组件（查询设备、查找主机、导出准备中等忙碌状态）；A39 音轨均衡条（选中且播放时跳动）；A41 预设删除收拢。减少动画开启时全部跳到终态。

**验收**：构建；真实鼠标键盘交互测试覆盖每项；真实屏幕截图复核 X1/X6 与视觉项；重启保持（预设删除、导入导出）；既有回归全套。静音，不打开/查询采集卡（D1 用文件源验证预览与状态行），不连接 PS5。
