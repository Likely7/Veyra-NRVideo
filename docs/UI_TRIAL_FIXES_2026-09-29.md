1. 交互共性（#1/#7a/#2/#3/#4/#6/#10/#16）——共享控件级修复，覆盖面最大。
2. 实时滑条与进度条（#5）、曲线（#11）、处理顺序定位（#9）、NR 层耗时（#7b）。
3. 性能球与状态灯条（#13/#15）、音频同步（#12）、导出入出点（#17）。
4. 节点画布（#14）与保护区域绘制（#8，含着色器）。
5. #18 诊断日志；全部完成后同一候选全量回归，再交用户试用。
