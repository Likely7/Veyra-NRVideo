# 专业模式文字与布局调整方案

状态：待用户确认，尚未实施面板重排。本轮仅增加直播兼容实验开关。

## 当前问题

当前 `SettingsWindow.cpp` 的增强页混放NR总开关、运行版本、超分、NR尺寸策略、保护区域和12组模型/残差参数；音频藏在补帧页底部。大量通过逐次增加y偏移插入的控件没有统一分组。固定区域占128逻辑像素，常驻版本/请求解释和大号还原按钮，实际可操作区偏小。用户必须记住参数位置并反复滚动，部分下拉框仅靠选项内容说明用途。

本方案的目标是：先找到功能，再调整参数。保持日常模式、玻璃视觉和视频区域布局；不以缩小字体和隐藏常用设置腾空间。重排不改变增强顺序、参数含义或算法。

## 面板结构

专业面板采用六个固定分类，窄面板也完整显示，不做横向隐藏滚动：

```text
画质          补帧          声音
显示          预设          导出
--------------------------------
当前分类标题              重置本页
本分类常用设置
本分类精细设置
```

六个分类使用两行三列、同宽按钮，位置始终固定。分类条总高约72逻辑像素。取消当前常驻两段技术提示，正常状态只保留一行“已生效 / 应用中 / 失败已恢复”。错误出现时展示原因，不用请求revision数字占主操作区；revision等移至诊断。全局还原默认保留在预设页，旁边明确作用范围。

| 分类 | 常用区域 | 后续区域 |
| --- | --- | --- |
| 画质 | 超分开关、算法、目标尺寸、质量；NR开关、运行版本、处理尺寸 | NR强度与局部调整、NR保护区域、残差细调、实验参数 |
| 补帧 | 补帧方式、倍率、内容帧率策略 | 光流来源与质量、AMD半尺寸选项；不再放声音 |
| 声音 | 同步方式、手动偏移、音量 | 音画偏差和设备恢复状态；当前没有的设备选择不伪造 |
| 显示 | 直播兼容模式、适应窗口/原始比例、全屏 | 原画/增强对比、分屏；明确区别于导出目标尺寸 |
| 预设 | 当前预设、保存、另存为、载入 | 重命名、删除、启动默认、还原全部默认 |
| 导出 | 格式、位置、开始导出 | 进度、暂停/取消、优先观看、限制说明 |

画质页再提供固定的“超分 / NR / 保护 / 细调”段落定位入口。点击滚动到对应段落，不另建四个深层页面，段落始终保持相同顺序。各分类记住自己的滚动位置。

## 文案统一

| 当前文字 | 建议文字 | 说明位置 |
| --- | --- | --- |
| 实验性 NVIDIA NR 增强 | NR 画面增强，旁附“实验”标记 | 悬停解释社区实验集成 |
| NVIDIA 原版 · RTX 50 | NVIDIA 原版 | 选项副文案：RTX 50；社区版RTX 40/50需实机验证 |
| 社区兼容 · RTX 40/50 实验 | 社区兼容版 | 实验标记与硬件验证范围保留 |
| 实时NR · 约1080内部处理 | 实时 | 始终显示实际内部处理尺寸，不只写“1080” |
| 原生NR · 高性能成本 | 原生 | 始终显示实际尺寸；性能成本放提示 |
| NR / DLSS光流 · 性能/平衡/质量 | 运动估算质量 | 选项仅写性能、平衡、质量 |
| 采集60→30fps处理（PS5 30帧） | 60Hz输入按30fps处理 | 提示说明这是处理策略，不是采集卡模式 |
| 采集音频同步 | 音画同步 | 文件和采集都使用；实际能力差异在状态中说明 |
| 增强变化量 | 增强混合 | 根据代码的残差含义逐项复核，不能写成锐化/降噪 |
| 局部明暗 / 局部结构 | 保留当前名称 | 没有画质证据前不擅自赋予算法新含义 |
| UI修正键 | UI修正（实验） | 与“NR保护区域”分开，不宣称可剔除游戏HUD |

不在选择框里重复字段名和长解释。中文字段为主，NR、DLSS、XeSS保留用于识别算法；厂商/API/数据格式等放组件页或悬停。数值统一小数位，单位贴在值后；未知延迟显示“未测”，不用0冒充。

## 实时状态

实时处理状态保留独立区域，首屏优先显示：源帧处理fps、有效补帧fps、显示提交fps、软件延迟。明确“软件延迟”测量起止；不得改叫包含采集卡和显示器的端到端总延迟。

下方为可展开阶段耗时：取帧、颜色、超分、光流、NR、补帧、呈现；并列阶段不可直接相加冒充总耗时。实际生效的运行版本、显示模式及失败原因放在这里，不在参数页重复多处。

## 尺寸与交互

- 面板宽度延续296至420逻辑像素可拖动范围；14px主字段、12px次要文字、16px组标题，按DPI缩放，不按窗口宽度缩字。
- 行高32至36，控件高度32，组间距16至20，标签到控件间距4至6；数值右对齐，长选项换到下一行。
- 面板顶部固定分类和状态，不滚动；内容按分类独立滚动。数值框、滑条、选择器继续禁止滚轮改值。
- 键盘Tab顺序与视觉顺序一致；焦点进入屏外控件时自动滚动定位。
- 提供面板设置搜索：输入“40 / 直播 / 30帧 / 音画 / 超分”等可列出对应字段，选中后跳到分类和位置并短暂高亮。搜索不能替代可见分组。
- 切换正在应用时显示“应用中”，失败显示恢复状态；避免进度文字刷新导致整块布局闪烁。

## 实施顺序和验收

1. 将绝对y偏移链改为各分类的顺序行布局；保持现有控件ID和回调，优先避免行为回归。
2. 实施六分类及声音迁移、画质段落定位、每页滚动记忆。
3. 整理文案、数字、单位及条件可用状态，再做搜索与状态压缩。
4. 验证所有原有设置仍能找到、修改、保存和恢复；日常模式不新增专业参数堆叠。

至少检查720x540、1040x540和1280x900，96/144/192 DPI下无重叠或截断，所有字段通过滚动和键盘可达。用户查找超分目标、NR版本、30fps处理、音画同步、直播兼容和导出，各自最多一次分类点击；画质细项最多再一次段落定位。实测交互和截图后才可称布局完成。
