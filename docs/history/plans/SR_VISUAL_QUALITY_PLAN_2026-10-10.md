# 超分实际画质优化（2026-10-10）

用户纠正：需求是已运行的超分画质改善不足，RTX Video SR、DLSS SR、FSR 都不明显；上一任务的执行路径修复和像素变化不是画质验收。本轮基于 c664a675c7b7a5c6cb54ed79c07b8a72127f4dfb，在 codex/sr-visual-quality-20261010 隔离排查和改善现有三个 SR 后端与共享输入/采样/输出接点。独立 start 保护45既有工作树、495脏文件及 main。后端必要接点覆盖历史QML迁移冻结，不派子Agent、不打测试包、不合并/push/Release/关机。

先核对原有SR的颜色、采样、运动/历史、NR残差和最终呈现链；没有证据不得把它们直接当原因。以用户GTA6 4K原图为共同参考，受控降采样到1080p再放大，NR/FG默认关闭，比较普通缩放、VSR1/4、DLSS、FSR；检查连续帧/静态累积，另核查NR组合和缩小显示。只拿输出差异不通过质量验收，不通过锐化强度冒充真实重建，也不承诺从已丢失的信息恢复准确原图。

测试代码只调用产品 EnhanceGraph/后端；可离线回读验证，正常播放/导出不新增像素回读、逐pass CPU等待、隐藏延迟或无界队列。先记录旧输出，针对明确接入缺口修复；新参数/后处理若确有需要必须可解释且有对照，优先已有成熟开源实现，记录固定来源/许可证；不换未知运行库/模型，不改原件或用户配置。默认避免强滤镜掩盖模型。

实际画质对照以原图误差/结构/边缘与逐像素裁切共同判断，纹理、文字、人脸、高反差边缘的恶化不能被一个全图平均值掩盖；动态部分关注拖影/闪烁/切镜。相对同源受控参考的指标不当作所有视频的提升百分比。验证产品构建、预览/导出共享合同及已修复的关闭项无重建；保持HDR和其他补帧现状。现场硬件边界如实报告，不拿N卡测试冒充AMD。

所有新产物在 E:/项目/Veyra/{build,tests,logs,tmp,reports,archives}/sr-visual-quality-20261010；源码在 worktrees 同名目录。构建复用只读已验缓存并核对源/头依赖闭包与SHA；私有runtime用硬链接共享，EXE/QML按原子替换防止改原件，不复制媒体/整个便携包。单测试≤300秒、构建≤900秒。施工与失败写WORKLOG/同轮REPORT，收尾commit/checkpoint/增量bundle/保护检查。前轮SR报告标注为执行修复已完成、画质优化未完成，保留原证据。

画质测试与性能测试分开：已有播放器进程不结束、不操作。仅独立无窗口 reference 测试可显式启用 quality-only-concurrent，且每项前要求本机空闲显存≥6000MiB、GPU占用≤20%；记录并发进程与资源读数，不从其墙钟时间推断性能。其他呈现/交互测试仍要求没有已有播放器。若资源不足，保留记录并暂停GPU测试。

实测追加范围：静止帧中光流导致DLSS/FSR历史漂移，零运动对照改善静止却恶化真实运动，因此仅SR增加保守静态假设校验。新增shaders/SrMotion.hlsl、CMake shader目标及独立SR motion纹理/生命周期；不改共享光流、NR/FG消费者或其shader。测试描述可关闭该校验取得同EXE对照，生产默认开启，仅DLSS/FSR实际超分且使用光流时分配。此为本轮用户SR授权所必需的构建接点，覆盖旧CMake冻结。

首次0.5/255局部阈值在运动夜景使DLSS参考MSE增加18.19%，不验收该实现。收紧为3×3逐像素完全一致、静态假设严格优于原光流才归零；同样好的匹配保留原向量。再次检查全部场景，增加真实NR/SR/DLSS2X、NR先行与AMD半尺寸光流的D3D12 debug回归；N卡上的AMD provider验证不代表AMD实卡验收。

严格3×3仍使DLSS运动夜景MSE增加11.31%，也撤回。最终只对整个光流输入RGB逐像素完全相同的重复帧归零SR运动，正常变化帧保留原向量/FlowAdapt尺度；SR独立R32_UINT标志、GPU精确比较/缩放两个pass，不回读到CPU、不更改共享流。新增SrStaticDetect shader及构建目标，clear使用非shader-visible CPU UAV描述符并显式barrier。用户确认主要1080p或以下→2K/4K，因此追加720p→2K/4K静止/运动参考，不能把重复帧修复声称为全面清晰度改善。

收尾决定（覆盖上段继续实验）：用户要求停止优化、撤回负优化。整帧重复检测虽在本次四段运动样本72张PNG与旧版逐字节相同，仍逐帧增加两个GPU pass与额外纹理，仅重复帧获益，不值得作为本次默认改变。因此所有SR生产实验均撤回c664a67，不继续720p测试；只保留共同原图参考测量工具和诚实的失败记录。源码CMake/EnhanceGraph/后端/着色器与基点相同，实验patch及两份shader留E盘archives而非产品。
