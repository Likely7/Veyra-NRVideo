Veyra 2.1.0 已发布！

这次重点更新：

1. AMD NR升级至lmxxf 0.44，RX9000可通过“启用性能优化版”切换Small/原模型，默认开启，支持每层独立选择并保存。此次不新增RX6000/7000的NR支持。
2. 新增FXAA/SMAA/MLAA抗锯齿，列表和节点都能用，可搭配超分改善边缘锯齿。RTX5070的4K标准测试开销约0.15–0.30ms，具体随素材变化。
3. 新增独立美颜效果器：磨皮与人脸原画保护分别开关，支持468点脸型轮廓、五官保护及多项调节。人脸原画保护可恢复之前全部效果处理前的人脸，减少NR过度改变人物。最终网格版单脸实测1080p约0.93ms、4K约1.42ms。
4. 修复采集卡分辨率、帧率和像素格式选不到/缺项，新增可搜索旧版完整列表及自定义尺寸检查；驱动不支持或擅自换格式时明确报错，相关设置与继续上次共用保存。

同时整合网络缓冲/重连、慢服务器播放、圆刚多声道音频、窗口捕获缩放恢复、专业全屏误暂停、极简全屏鼠标不隐藏及导出/节点保存等修复。新6群二维码已更新到README和发布页。
