# Veyra 2.0.5 本地测试版

请解压到新目录运行 `veyra_qml_ui.exe`，勿混装旧运行库。NVIDIA和AMD包来自同一生产源码/EXE，保留原有厂商组件和许可证。本次供测试，公开版仍为2.0.4。

- AMD默认补帧优先FSR；旧配置里不可用的DLSS/VFG选择迁移到可用FSR，其次XeSS，保留启用状态和已有可用手动选择。
- FSR视频补帧导出保留所选后端，不再错误替换为DLSS。XeSS现有集成无可编码纹理，导出会明确提示改选FSR、DLSS或VFG。
- AMD视频NR允许原高分辨率输出，内部模型最高1080p，残差合成回原尺寸；图片模型预算不变。此前RX9000预览通过反馈不代表此次AMD离线推理/编码已通过实卡验收。
- 自动显示同步使用垂直同步，适用于窗口/全屏；仍可手动允许撕裂。软件API验证不等于用户显示器的撕裂、VRR或屏幕延迟已经验收。
- 修复实时统计动画与NR争抢GPU。上一轮RTX5070、普通优先级、原版单层1080p NR：GTA VI 4K30旧/新约6.559/6.559ms；M2 4K60约6.633/6.590ms。该数据来自fix2匹配验证，不冒充本次2.0.5的新性能数据，不外推所有设备。
- 保留OBS兼容模式重绘、多NR导出、PR19 HDR调优及PR20构建兼容修复、光流列表预设等已完成改动。

**NV显存持续增长尚未修复。** 用户决定延期到下一版深入排查，本包没有把Shutdown疑点当成根因修改。真实AMD HIP/硬件编码、用户显示器与真实主机/采集长稳仍需实卡复测。实际本轮检查与失败记录见 `docs/RELEASE_2.0.5_ACCEPTANCE_2026-10-07.md`；组件及载荷身份见 `package-manifest.json`。旧版本说明保留作历史材料。
