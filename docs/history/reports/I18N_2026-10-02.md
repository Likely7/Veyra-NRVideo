# 界面多语言（2026-10-02）

设置 → 通用与外观 → 界面语言：跟随系统 / 简体中文 / 繁體中文 / English / 日本語，立即生效，保存在 `qml-preferences.v1.json` 的 `language`。「跟随系统」：Windows 为繁体中文（台湾、香港、澳门或繁体脚本）→ 繁體中文，其他中文 → 简体中文，日文 → 日本語，其余 → English。**日志始终保持中文**，方便读用户反馈。

## 结构

- 简体中文是源语言，也是查表的键。QML 用 `qsTr("中文")`，C++ 界面层用 `tr("中文")`。
- 同一个中文有两种意思时加消歧义：`qsTr("关闭", "off")`（设置项的「关」）和 `qsTr("关闭")`（关闭窗口）；`qsTr("播放", "section")`（设置分区「播放」）。
- 引擎送到界面的消息（状态、错误、说明）不经过 `tr()`，在桥接层用 `uiText()` / `i18n::text()` 翻译：先整句匹配；含 `std::format` 的 `{}` 槽位按模式匹配；以「：」结尾的前缀带后续内容；再按 `；`、换行、` · ` 拆段逐段翻译；末尾 `[...]` 标签原样保留。路径、设备名、预设名、LUT 名这类数据仍用 `utf8Of()`，不翻译。
- 翻译表 `i18n/catalog.json`，编译进程序（Qt 资源），每条 `zh` / `ctx` / `zh-TW` / `en` / `ja`。缺翻译时显示中文原文。
- 字体：日文 Yu Gothic UI，繁中 Microsoft JhengHei UI，其他 Noto Sans SC（`Theme.fontUi` 跟随 `Qt.uiLanguage`）。
- 代码：`include/veyra/ui/UiLanguage.h`、`src/ui/UiLanguage.cpp`（库 `veyra_ui_i18n`），测试 `tests/unit/UiLanguageTests.cpp`（`veyra_ui_i18n_tests`）。

## 加新文字以后

1. QML 里新写的中文：`python -B scripts/i18n/wrap_qml.py --report` 看比较/判断里用到的中文，确认两边一致后 `--apply`（跨行字符串会被列出、不自动处理）。C++ 界面文字直接写 `tr("...")`。
2. `python -B scripts/i18n/extract.py`：收集新字符串，保留已有翻译，删掉不再使用的。
3. `python -B scripts/i18n/to_traditional.py`：填繁体（台湾用语表 + Windows 简繁转换 + 一对多字修正）；`--all` 全部重新生成（会覆盖手改）。
4. 补 `en` / `ja`，`python -B scripts/i18n/extract.py --check` 检查缺失和占位符（`{}`、`%1`）数量。
