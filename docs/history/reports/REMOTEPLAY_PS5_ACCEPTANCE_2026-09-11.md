# PS5 串流实机验收

2026-09-12：用户已确认连接、基本增强及本轮修复测试没问题。当前修复/证据与未覆盖场景见[施工记录](REMOTEPLAY_REPAIR_PROGRESS_2026-09-12.md)。PS5面板支持仅观看与陀螺仪校准；校准时平放手柄并返回播放器，等待120个稳定样本。仅观看需要重新连接，不承诺绕过PS5账号占用规则。

开发分支 `agent/remoteplay-integration` 的本机测试版；不是已发布的0.0.4便携包。

## 打开哪个程序

直接打开 `out/remoteplay/product-repair/veyra.exe`。该目录已有FFmpeg运行依赖和shader，NR/SR/FG沿用项目现有本机运行组件。不要把exe单独拖到别的目录。也可使用桌面的 **Veyra PS5 测试版** 快捷方式，它从空白画面启动并关闭初始NR/SR/FG，便于先验收原始串流。

日常模式底栏时间信息旁有 **PS5** 按钮；专业模式左侧也有PS5入口。

## 第一次配对

1. 电脑与PS5在同一局域网，优先有线。PS5进入“设置 → 系统 → 远程游玩”，启用远程游玩。
2. 在“关联设备”取得8位配对码。Veyra点击PS5，输入主机IP，或点击“查找主机”。
3. 输入 **PSN Account ID**（数字ID，或对应8字节的Base64）与配对码。Account ID不是PSN昵称；不清楚时参考 [chiaki-ng官方配置说明](https://streetpea.github.io/chiaki-ng/setup/configuration/#registering-your-playstation) 中的 PSN Login / Public Lookup 获取方式。本版没有内置PSN账号登录或公网中继。已配对主机可从地址下拉框选择，删除配对不会停止当前串流。
4. 初次选 **1080p · 60 fps / H.264 · SDR / 15 Mbps**，点击“配对并保存”。成功后点击“连接并观看”。
5. 若主机要求登录PIN，填写单独的登录PIN栏；它与8位配对码不同。
6. 连接状态/错误显示在面板内；“断开连接”或播放器“停止”可结束串流。关闭设置面板会保留播放。

配对资料以当前Windows用户DPAPI加密保存在 `runtime_local/remoteplay/*.dat`（兼容此前单profile的 `runtime_local/remoteplay-profile.dat`）。同一台电脑下次直接连接；复制该文件到另一台电脑/另一个Windows用户不能代替重新配对。该文件不要作为日志附件。

## 建议按这个顺序测

| 项目 | 操作 | 观察 |
| --- | --- | --- |
| 基础连接 | 全关增强，H.264 1080p60，播放有运动与声音的内容 | 首帧、持续画面、声音连续、处理FPS |
| 手柄 | USB连接DualSense，点击Veyra主窗口使其在前台 | 按钮、双摇杆、双扳机、PS与触摸板点击；切去别的窗口应归零 |
| 编码格式 | 断开后分别连接H.265、720p、30fps | 不黑屏、不错误显示尺寸，声音速度正常 |
| 增强 | 基础通过后依次开启NR、超分、2X补帧，再组合开启 | UI显示真实处理/提交指标；增强欠速时声音仍独立播放，不积压压缩帧 |
| 操作 | 全屏、窗口缩放、专业模式、参数重建、停止后重连 | 不崩溃，历史正确重置，无持续按键 |
| 网络恢复 | 临时断开网络再恢复，必要时手动重连 | 出错提示/恢复请求，不无限缓存或无响应 |
| 唤醒 | PS5允许待机联网和网络唤醒后，待机时点“唤醒已配对PS5” | 只说明请求发出，等主机启动后再连接 |
| 录制 | 使用WGC窗口捕获Veyra | 有视频，不仅有UI；捕获节奏需实测 |

每次定位问题先保持单个场景不超过5分钟。出错请给出：H264/H265、720/1080、30/60、NR/SR/FG状态、发生操作，以及 `logs/veyra-app.log`（本机普通启动）。不要仅以目标FPS判断实际处理性能。

## 已验证和仍未知

已验证源码构建、离线真H264/H265解码、PCM与PTS、帧序号回绕、DPAPI、latest解码帧mailbox、SDL初始化/失焦neutral、真实面板本地校验及既有播放器软件gate。没有连接PS5，不能据此宣称配对/网络/真实码流/实际手柄/真实声音同步已经通过。

本版Remote Play为 **局域网PS5、SDR、720p/1080p、30/60fps、FFmpeg软件解码**。增强仍走现有D3D12图。没有把接收时间当成PS5原生PTS：相对时间和音画固定偏移为本地估计，实机需校对。尚无HDR、公网PSN穿透、触摸板坐标、陀螺仪、麦克风或震动/自适应扳机回传承诺。罕见Chiaki join失败目前为拒绝复用/隔离清理路径，未做真实join失败注入。
