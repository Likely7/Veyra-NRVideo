# Veyra 2.0.0 Beta 测试说明

> 2026-09-30 后续反馈修复只形成独立本机候选，原beta目录/ZIP未修改。当前候选的NR双版本、纯播放全屏同步、HDR/motion/5–7K等变化与未完成项见 [本轮执行记录](FIELD_ISSUES_EXECUTION_2026-09-30.md)。候选包含本机AMD/Intel路径引用，不能套用下方旧beta“整个文件夹可拷走”的说明；本轮尚未制作新便携包。

新界面程序是 `veyra_qml_ui.exe`。整个文件夹可以直接拷到别的电脑上运行，设置和日志都存在这个文件夹里，
不会碰 1.4.4 的配置。

## 每台机器都测

1. 打开一个 4K 或 1080p 视频，开 NR，看画面是否正常、帧率是否稳定。
2. 开 DLSS 补帧，依次试 2X、3X、4X、6X（40/30 系能开到几倍就试到几倍），看补帧是否生效、有无花屏、卡顿或崩溃。
3. 专业模式 → 质量页 → 「输出稳定器 · 抗闪烁」：打开后看静止画面的闪烁是否减少、运动画面有无拖影。
4. NR 层 → 实验 → 打开「时间域防闪烁」，切换四个抗闪烁档位，看画面和流畅度。
5. 保存一个带多层 NR 的预设，重启软件后读回，确认设置没丢。

## 各代显卡的重点

| 显卡 | 重点 |
| --- | --- |
| RTX 50 | 补帧走 NVIDIA 原生路径（不打补丁）；NR 默认用 Lecram，看是否正常、是否比 1.4.4 略省 |
| RTX 40 | 补帧走 310.9.1 + DLSSG-Transfusion 补丁（Ada）。**重点看补帧能否打开、3X/4X/6X 是否可用、HUD/文字是否比 1.4.4 稳** |
| RTX 30 | 补帧走 310.9.1 + Transfusion 补丁（Ampere，带优化内核）；NR 用 SF-v2。**重点看两者能否打开、帧率多少** |

## 补帧打不开时换回旧方案（30/40 系）

1. 完全退出软件。
2. 备份 `runtime\experimental\nvngx_dlssg.dll`。
3. 把 `runtime\experimental\fallback-dlssg-310.7\nvngx_dlssg.dll` 复制到 `runtime\experimental\`，覆盖同名文件。
4. 重新打开软件：会自动回到 1.4.4 的 310.7 解锁方案。请把换回前后的表现都记下来。

## 反馈时请附上

- 显卡型号、驱动版本、Windows 版本；
- `logs\veyra-qml.log`（出问题后先退出软件再拷，文件里有补帧补丁是否生效的记录，搜 `fg-compat`、`transfusion`、`nr-ampere`）；
- 出问题时的截图或录屏。

## 已知情况

- 本包只在 RTX 5070 上做过验证。40/30 系的补丁和 SF-v2 在实卡上完全没测过，这正是本次要测的。
- 补帧优化内核和社区 NR 运行库都是实验组件，不代表 NVIDIA 认证或支持，也没有作者授权，仅供内部测试，请勿外传。
